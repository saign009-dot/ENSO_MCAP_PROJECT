#ENSO_MCAP_PROJECT  

For this code to work on your machine:
 - Open a terminal 
 - Navigate to your local folder/repo, type -> cd "C:\your\path\here\ENSO_MCAP_Project"
 - Create your Python virtual environment, type or copy/paste -> python -m venv ENSO.venv
 - Install the packages to your environment, type or copy/paste -> .\ENSO.venv\Scripts\python.exe -m pip install -r requirements.txt
