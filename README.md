#ENSO_MCAP_PROJECT  

For this code to work on your machine:
 1.  Open a terminal 
 2. Navigate to your local folder/repo, type -> cd "C:\your\path\here\ENSO_MCAP_Project"
 3. Create your Python virtual environment, type or copy/paste -> python -m venv ENSO.venv
 4. Activate your virtual Python environment, type or copy/paste -> .\ENSO.venv\Scripts\Activate.ps1
 5. Install the packages to your environment, type or copy/paste -> .\ENSO.venv\Scripts\python.exe -m pip install -r requirements.txt
